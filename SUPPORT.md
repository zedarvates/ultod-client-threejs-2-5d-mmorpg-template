# Support

## Current support level

Documentation review only. No browser engine, WebGL/WebGPU runtime or Zig server combination is currently supported.

## Public issues may cover

- Ambiguous or broken documentation
- Missing publication or security boundaries
- Proposed original architecture decisions
- Reproducible problems in a future public starter

## Not supported

- Proprietary Ultimate Odycer clients or servers
- Production deployment, player accounts or live realms
- Historical protocol implementations
- Commercial, administration or billing systems
- Third-party assets and unreviewed modifications

Security reports containing sensitive details must use GitHub private vulnerability reporting. Compatibility requests must name the exact versions and environment; unsupported combinations must not be presented as defects in released behavior.
